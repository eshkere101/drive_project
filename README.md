Этот игровой проект был разработан в рамках прохождения курса Samsung GameDev для преподавателей (2025).

Игра "Drive"

Игрок должен объезжать другие машины и избегать столкновений. Задача — продержаться как можно дольше, зарабатывая очки за время. Игра заканчивается, если закончились жизни игрока. Управление машиной - нажатие на экран
